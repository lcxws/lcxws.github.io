# 人品算法生成器 · 运算逻辑说明

> 本工具 100% 瞎编，仅供娱乐。八字与五行标签基于传统公式，人品值与全部鉴定文案为随机话术。

对应文件：`index.html`（页面与算法）、`poems.js`（古诗背景数据）。

## 一、输入

- 姓名（必填）
- 生日 `YYYY-MM-DD`（必填）
- 出生时间 `HH:MM`（可选，用于推演时柱）

## 二、四柱八字推算

### 1. 年柱（公历年份直接套公式）

```
天干 = (年 - 4) mod 10      地支 = (年 - 4) mod 12
```

例：2000 年 → 庚辰。

### 2. 月柱（按公历月份近似，未做节气精确处理）

```
地支 = 月份 mod 12
天干 = 五虎遁起月表[年干 mod 5] + 月 - 2   (mod 10)
```

五虎遁起月表（按年干分组）：`甲己→丙(2)、乙庚→戊(4)、丙辛→庚(6)、丁壬→壬(8)、戊癸→甲(0)`。

### 3. 日柱（真实六十甲子，基准 1900-01-01 = 甲戌日）

```
天数 = 自 1900-01-01 起累加天数（含闰年）
日序 = (10 + 天数) mod 60
天干 = 日序 mod 10      地支 = 日序 mod 12
```

已验证：1949-10-01 = 甲子、2000-01-01 = 戊午、2008-08-08 = 庚辰。

### 4. 时柱（按所填出生时间，十二时辰）

```
地支 = ⌊(小时 + 1) ÷ 2⌋ mod 12     // 00:00→子、12:00→午、23:00→子
天干 = 五鼠遁起时表[日干 mod 5] + 时支   (mod 10)
```

五鼠遁起时表：`甲己→甲(0)、乙庚→丙(2)、丙辛→戊(4)、丁壬→庚(6)、戊癸→壬(8)`。

未填出生时间时：`时支 = FNV-1a(姓名) mod 12`。

## 三、五行统计

八个字（4 天干 + 4 地支）各查表映射五行：

```
天干：甲乙→木、丙丁→火、戊己→土、庚辛→金、壬癸→水
地支：子→水、丑→土、寅→木、卯→木、辰→土、巳→火、午→火、未→土、申→金、酉→金、戌→土、亥→水
```

统计出 `木×n 火×n 土×n 金×n 水×n`，计数为 0 者标「五行缺 X」，计数最高者标「X 旺」。

## 四、人品值（AES-256）

```
密钥   = SHA-256(生日字符串)               // 32 字节
明文   = UTF-8(姓名)
密文   = AES-256-ECB(明文, PKCS7 填充)     // 纯前端 JS 实现，不联网
hex    = 密文十六进制（大写）
人品值 = hex 前 7 个字符中的数字部分         // 例 A1B43B1 → 1431
       → 若为空，取全 hex 中前 7 位数字；再空则 666
```

## 五、文案生成（解释学部分）

```
种子 = FNV-1a(姓名 + "|" + 生日 + "|" + 人品值)
```

用种子对各个话术池取模随机（同一输入结果固定，避免每次刷新变卦）：

- 性格句：按日主五行（`日干 ÷ 2` 得到五行索引）选择对应池
- 五行缺 / 五行旺 各一句；名讳一句
- 人品档位：`<5000 低 / 5000–8999 中 / ≥9000 高`
- 事业 / 财运 / 感情 / 健康 / 贵人 / 今日宜忌 六段（用种子偏移错开，避免相邻两句撞车）
- 综合判定 + 开运吉祥话（按日主五行，缺五行时再补一条对应五行吉祥话）

## 六、主题与背景

- 22:00–次日 4:00 → 夜间版；其余时间 → 白天版
- 手动切换按钮写入 `localStorage("lcxwsTheme")`，此后不再受时间影响
- 夜间版只留古诗背景（隐藏粒子光斑）；白天版保留粒子
- 古诗背景：`poems.js` 内含 205 组（每句两半句合并为一联），随机取约 28 行分三层景深滚动：
  - 远景 14 条：小字号、模糊、半透明、飘得慢
  - 中景 9 条：中字号、微模糊
  - 近景 5 条：大字号、清晰、飘得快
- 竖排排版 `writing-mode: vertical-rl`，字体 KaiTi（楷体），夜间白字、白天黑字
